About

Kinetic is injected into Counter-Strike 2 and works from the inside. It asks the engine's own schema where every field lives, so an update changes nothing. It paints bodies through the game's material system, so chams know exactly whose body they are on. It writes a jump into the input the game is about to read, so a bunny hop lands on its tick.

It is one person's project, built in the open and tested against bots on an insecure server. Nothing is for sale.
